ARCHITECTURE AT A GLANCE
================================================================================

SHARED DATA LAYER (single code path):
  └─ SSURGO query → DEM fetch (LS) → R-factor (NOAA) → EI calculation
     └─ Wetland detection (SSURGO + NLCD + NHD)

TIER 1: FARMER VIEW (non-technical, actionable)
  ├─ HEL Status badge (Yes/No/Maybe with color)
  ├─ Wetland Status (Yes/No)
  ├─ Next Step (always "Contact NRCS")
  ├─ Find NRCS Office button (with map & contact info)
  ├─ Print results (simple 1-page PDF)
  └─ Share link (shareable URL with embedded results)
  
  HIDDEN: R, K, L, S factors | Component table | AD1026 form | Technical details

TIER 2: CONSERVATIONIST VIEW (technical, export-ready)
  ├─ Tab 1: Results Overview (EI metrics, HEL status, confidence)
  ├─ Tab 2: Field Verification (checklist + automated vs field comparison)
  ├─ Tab 3: Component Breakdown (full table of all soil components)
  ├─ Tab 4: AD1026 Pre-fill (read-only R, K, LS, T → download PDF form)
  ├─ Tab 5: Technical Details (uncertainty ranges, data provenance, methodology)
  └─ Tab 6: Export & Download (CSV, PDF report, AD1026 form)
  
  HIDDEN: NRCS office finder | Simple status badges
